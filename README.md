# Крестик

Схемы для вышивки крестом: из фотографии или по готовой схеме, только нитки DMC, отметка прогресса, работает без интернета.

Прогрессивное веб-приложение (PWA): откройте страницу в Chrome на Android → меню ⋮ → «Установить приложение». Все данные (фото, схемы, прогресс) хранятся только на устройстве.

Палитра DMC: [makebead/craft-color-codes](https://github.com/makebead/craft-color-codes) (CC BY 4.0).
